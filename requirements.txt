# obsidianchain runtime + test dependencies

# Every version is pinned exactly, including transitive dependencies, so
# that `make vendor` produces a byte-identical wheel set and the image
# builds reproducibly. All of these install from wheels only - no
# compilers, no CUDA, no runtime network access. matplotlib is used with
# the Agg backend only - no display, no interactive GUI toolkit, and its
# wheel bundles the DejaVu fonts so no system fonts are needed either.
#
# These pins are architecture-neutral: every package below publishes both
# manylinux x86_64 and aarch64 wheels, so the same file serves linux/amd64
# (the primary team/SIH target) and linux/arm64 (Apple silicon dev).
# The architecture is chosen by PLATFORM at vendor time, not here.
#
